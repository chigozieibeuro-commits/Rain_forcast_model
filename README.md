Rain Forecast Prediction 

Overview

This project uses Machine Learning to predict rainfall and integrates the trained model into a FastAPI application for practical use.

Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- FastAPI
- Uvicorn
- Pydantic
- Joblib
- PostgreSQL
- Psycopg2

Features

- Rainfall prediction using Machine Learning
- Model training and evaluation
- REST API for making predictions
- Input validation using Pydantic
- Model loading using Joblib
- PostgreSQL database integration

Goal

To build a Machine Learning model and integrate it into an application
that can be used to make rainfall predictions.
